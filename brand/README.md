# Marca — Zela

Identidade visual do Zela. Cor principal: **`#4BB9FA`** (azul-céu) + branco.

## Cores

| Uso | Cor |
| --- | --- |
| Azul principal | `#4BB9FA` |
| Azul escuro (contraste / acentos) | `#2E9BE6` |
| Branco | `#FFFFFF` |

> O símbolo tem um leve degradê de azul; `#4BB9FA` é a cor média, ótima como token principal.
